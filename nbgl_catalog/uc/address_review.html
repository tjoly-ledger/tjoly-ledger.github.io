nbgl_useCaseAddressReview

Shows an address for the user to check against their wallet, with optional extra pairs. The address page also carries a button to display it as a QR code, which is not captured here: it is an icon with no label, so it cannot be located the same way on every product.

Needs ENABLE_NBGL_QRCODE = 1 in the app Makefile. 

void nbgl_useCaseAddressReview(const char                       *address,
                               const nbgl_contentTagValueList_t *additionalTagValueList,
                               const nbgl_icon_details_t        *icon,
                               const char                       *reviewTitle,
                               const char                       *reviewSubTitle,
                               nbgl_choiceCallback_t             choiceCallback);

With extra pairs 4 screens

Extra tag/value pairs are shown after the address, for an account name or a derivation path.

10 lines every variant of this page repeats#define ADDRESS "bc1qar0srrr7xfkvy5l643lydnw9re59gtzzwf5mdq"

static nbgl_contentTagValue_t     pairs[2];
static nbgl_contentTagValueList_t pairList;

/** The status page an app shows once the user has answered. */
static void uc_address_review_choice(bool confirm) {
    nbgl_useCaseReviewStatus(
        confirm ? STATUS_TYPE_ADDRESS_VERIFIED : STATUS_TYPE_ADDRESS_REJECTED, catalog_on_quit);
}


pairs[0].item = "Account";
pairs[0].value = "Main account";
pairs[1].item = "Derivation path";
pairs[1].value = "m/44'/0'/0'/0/0";

pairList.pairs = pairs;
pairList.nbPairs = 2;
pairList.wrapping = true;

nbgl_useCaseAddressReview(ADDRESS,
                          &pairList,
                          &CATALOG_ICON_APP,
                          "Verify BOL address",
                          "Make sure it matches the one\nin your wallet.",
                          uc_address_review_choice);
