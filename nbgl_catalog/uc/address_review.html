nbgl_useCaseAddressReview

Shows an address for the user to check against their wallet, with optional extra pairs. The address page also carries a button to display it as a QR code, which is not captured here: it is an icon with no label, so it cannot be located the same way on every product.

Needs ENABLE_NBGL_QRCODE = 1 in the app Makefile.

const char * address

address to confirm (NULL terminated string)

const nbgl_contentTagValueList_t * additionalTagValueList

list of tag/value pairs (can be NULL) (must be persistent because no copy)

This structure contains a list of [tag,value] pairs

  • pairs const nbgl_contentTagValue_t *array of [tag,value] pairs (nbPairs items). If NULL, callback is used instead
  • callback nbgl_contentTagValueCallback_tfunction to call to retrieve a given pair
  • nbPairs uint8_tnumber of pairs in pairs array (or max number of pairs to retrieve with callback)
  • startIndex uint8_tindex of the first pair to get with callback
  • hideEndOfLastLine boolif set to true, replace 3 last chars of last line by "..."
  • nbMaxLinesForValue uint8_tif > 0, set the max number of lines for value field.
  • token uint8_tthe token that will be used as argument of the callback if icon in any tag/value pair is touched (index is the index of the pair in pairs[])
  • smallCaseForValue boolif set to true, a 24px font is used for value text, otherwise a 32px font is used
  • wrapping boolif set to true, value text will be wrapped on ' ' to avoid cutting words
  • actionCallback nbgl_contentActionCallback_tcalled when a valueIcon is touched on a given pair

const nbgl_icon_details_t * icon

icon used on the first review page

Represents all information about an icon

  • width uint16_twidth of the icon, in pixels
  • height uint16_theight of the icon, in pixels
  • bpp nbgl_bpp_tbits per pixel for this area
  • isFile boolif true, the bitmap buffer contains an image file
  • bitmap const uint8_t *buffer containing pixel values

const char * reviewTitle

string used in the first review page

const char * reviewSubTitle

string to set under reviewTitle (can be NULL)

callback called when transaction is accepted (param is true) or rejected (param is false)

prototype of choice callback function

arguments

static nbgl_contentTagValue_t     pairs[2];
static nbgl_contentTagValueList_t pairList;

/** The status page an app shows once the user has answered. */
static void uc_address_review_choice(bool confirm) {
    nbgl_useCaseReviewStatus(
        confirm ? STATUS_TYPE_ADDRESS_VERIFIED : STATUS_TYPE_ADDRESS_REJECTED, catalog_on_quit);
}


pairs[0].item = "Account";
pairs[0].value = "Main account";
pairs[1].item = "Derivation path";
pairs[1].value = "m/44'/0'/0'/0/0";

pairList.pairs = pairs;
pairList.nbPairs = 2;
pairList.wrapping = true;

nbgl_useCaseAddressReview(ADDRESS,
                          &pairList,
                          &CATALOG_ICON_APP,
                          "Verify BOL address",
                          "Make sure it matches the one\nin your wallet.",
                          uc_address_review_choice);
