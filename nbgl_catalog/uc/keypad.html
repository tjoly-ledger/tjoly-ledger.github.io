nbgl_useCaseKeypad

A PIN entry page. The digits can be hidden and the key layout shuffled.

Needs ENABLE_NBGL_KEYPAD = 1 in the app Makefile. 

void nbgl_useCaseKeypad(const char             *title,
                        uint8_t                 minDigits,
                        uint8_t                 maxDigits,
                        bool                    shuffled,
                        bool                    hidden,
                        nbgl_pinValidCallback_t validatePinCallback,
                        nbgl_callback_t         backCallback);
Visible digits 5 screens 
// The backspace and validate keys appear on their own, as soon as
// `minDigits` is reached.
nbgl_useCaseKeypad("Enter your PIN",
                   4,      // minDigits
                   8,      // maxDigits
                   false,   // shuffled: scramble the key layout
                   false,   // hidden: replace the digits by dots
                   uc_keypad_validate,
                   catalog_on_quit);
