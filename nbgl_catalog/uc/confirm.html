nbgl_useCaseConfirm

A modal page drawn on top of the current screen, to confirm a decision. The review behind it is only there to give the modal the page an app would have.

nbgl_use_case.h ↗ 
void nbgl_useCaseConfirm(const char     *message,
                         const char     *subMessage,
                         const char     *confirmText,
                         const char     *rejectText,
                         nbgl_callback_t callback);

const char * message

string to set in center of page (32px)

const char * subMessage

string to set under message (24px) (can be NULL)

const char * confirmText

string to set in button, to confirm

const char * rejectText

string to set in footer, to reject

the SDK documents this one as cancelText

nbgl_callback_t callback

callback called when confirmation button is touched

prototype of generic callback function
