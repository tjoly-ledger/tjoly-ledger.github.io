Home & settings

nbgl_useCaseHomeAndSettings 4 variants The app home page, with its optional action button, plus the auto-paginated settings and info pages reached through the top-right gear. nbgl_useCaseGenericSettings 1 variant The settings and info pages of nbgl_useCaseHomeAndSettings(), without the home page, for an app that draws its own. nbgl_useCaseGenericConfiguration 1 variant A titled set of configuration pages built from any mix of content types: switches, radio choices, touchable bars, infos. nbgl_useCaseNavigableContent 1 variant One level of generic pages with a touchable header, where the app fills each page on demand through a navigation callback.

7 use cases

Review

nbgl_useCaseReview 6 variants Full review of an operation whose tag/value pairs are all known upfront: a cover page, as many auto-paginated pair pages as needed, then a long-press page to sign. nbgl_useCaseReviewBlindSigning 1 variant The same review, preceded by a blind signing warning page. It also takes a tip-box, but never displays it: see the tip-box variant of nbgl_useCaseAdvancedReview() for that. nbgl_useCaseAdvancedReview ENABLE_NBGL_QRCODE 7 variants The configurable review: a bitfield of predefined warnings drives the intro pages, and the top-right button of the first and last pages opens the matching details. nbgl_useCaseReviewLight 1 variant The same flow as nbgl_useCaseReview(), but the last page validates with a simple button instead of a long press. nbgl_useCaseGenericReview 4 variants Any mix of content types paginated as a review, with a reject footer, when the predefined reviews do not fit. nbgl_useCaseReview ENABLE_NBGL_QRCODE 5 variants A tag/value pair whose value is an alias: the review shows the short name with a chevron, and the page behind it justifies the alias. The aliasType of nbgl_contentValueExt_t picks that page. nbgl_useCaseReview 3 variants The layout fields a tag/value pair carries itself, which decide how a review paginates and draws it. The list-level ones are not here: nbgl_useCaseReview() overrides smallCaseForValue, nbMaxLinesForValue and hideEndOfLastLine on every page it draws, so an app cannot set them.

Streaming review

nbgl_useCaseReviewStreamingStart 2 variants Opens a review whose pairs are not all known yet: it draws the cover page, then the app calls Continue() for every chunk it parses and ends with Finish(). nbgl_useCaseReviewStreamingBlindSigningStart 1 variant The streaming cover page preceded by a blind signing warning page. nbgl_useCaseAdvancedReviewStreamingStart ENABLE_NBGL_QRCODE 2 variants The configurable streaming start: the same warning bitfield as nbgl_useCaseAdvancedReview(). nbgl_useCaseReviewStreamingContinue 1 variant Draws the pages of the chunk the app has just parsed. It only renders inside a chain, so the whole chain is played here. nbgl_useCaseReviewStreamingContinueExt 1 variant The same as Continue(), plus a Skip button whose callback is expected to jump straight to the signing page. Needs SKIPPABLE_OPERATION on the start. nbgl_useCaseReviewStreamingFinish 1 variant Closes a streaming review with the long-press signing page. Shown here at the end of the whole chain.

Address

nbgl_useCaseAddressReview ENABLE_NBGL_QRCODE 3 variants Shows an address for the user to check against their wallet, with optional extra pairs. The address page also carries a button to display it as a QR code, which is not captured here: it is an icon with no label, so it cannot be located the same way on every product.

Status, choice & confirm

nbgl_useCaseStatus 2 variants A transient page with a free text, closing on its own after 3 seconds. The emulated time is frozen here so it can be captured. nbgl_useCaseReviewStatus 8 variants The same transient page, pre-worded for each of the eight values of nbgl_reviewStatusType_t. nbgl_useCaseChoice 2 variants A centered info page with a black confirm button and a footer to decline. nbgl_useCaseChoiceWithDetails 2 variants The same choice page, plus a top-right button opening a details modal: either one centered page, or a list of bars drilling down into sub-pages. nbgl_useCaseAdvancedChoiceWithDetails 1 variant The choice page with a title line and a header icon on top of the centered one, plus the details modal. nbgl_useCaseConfirm 2 variants A modal page drawn on top of the current screen, to confirm a decision. The review behind it is only there to give the modal the page an app would have. nbgl_useCaseAction 1 variant A centered info page with a single action button.
